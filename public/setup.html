Quick steps

  1. Download the installer for your computer, or download the raw zip if your device needs manual setup.
  2. If using the raw zip, extract it into a folder you will keep. Chrome needs the folder, not the zip file.
  3. Open chrome://extensions, turn on Developer mode, and click Load unpacked.
  4. Choose the Timebox extension folder, then test it by opening YouTube.

Compatibility notes

Desktop Chrome uses the same manual extension flow on Windows, Mac, Linux, and Chromebook: Developer mode, then Load unpacked.

Mobile Chrome and managed school/work devices may block extension installation. If Chrome will not show Developer mode or Load unpacked, use a personal desktop computer.
