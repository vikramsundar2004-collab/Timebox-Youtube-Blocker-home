Desktop Chrome setup

Install it in a few minutes.

Chrome extensions do not install inside Chrome on iPhone. If you pay on mobile, save the license key and use it later on a desktop computer.

Windows

  1. After paying, click Download for Windows.
  2. Open the downloaded .cmd file. Windows may ask you to confirm because it is a script.
  3. The script creates a Timebox extension folder and opens the Chrome extensions page.
  4. Turn on Developer mode, click Load unpacked, then choose the Timebox folder that opened.

Mac

  1. After paying, click Download for Mac.
  2. Open the downloaded .command file. If macOS blocks it, right-click the file and choose Open.
  3. The command creates a Timebox extension folder and opens Chrome’s extensions page.
  4. Turn on Developer mode, click Load unpacked, then choose the Timebox folder.

After the Chrome Web Store listing is approved

The easiest install path will be the official Chrome Web Store button. This download path is here so people can still use the real extension for your class presentation while the store review finishes.
